# 星愿池小红书推广文案

为星愿池（鸿蒙亲子目标打卡 App，stars-collection 项目）的功能页写小红书种草文案：一张配图 + 一篇文案成对发布。方法论全部继承 `app-promo-texts` skill（**先读它**），本篇只给星愿池专属的固定值与范文索引。

## 与 app-promo-texts 的差异点（本 skill 负责的部分）

| 骨架位置 | 星愿池固定值 |

| 首行标题 | `【星愿池·功能名】`（功能名 3-6 字，如 桌面卡片/成长档案） |
| 过渡句 | `星愿池怎么帮你<做的事>？` / 延续页功能可用 `星愿池怎么<动作>？`（如「星愿池怎么兑换？」） |

## 星愿池文案特有约定

- **受众分层**：先定篇偏「成人自律」还是「亲子养娃」——星图/桌面卡片/统计/兑换偏成人语气；成长档案是家长视角（「孩子的身体数据极其私密」，隐私说得最重）
- **星星经济自洽**：树愿池的星星靠打卡获得、不能花钱买——涉及兑换/奖励的文案必须保持这个口径（「星星靠打卡获得，不用花钱买」）
- **涉儿童健康必加免责**：成长档案篇收尾前加「（温馨提示：参考标准仅供日常记录参考，不构成医学建议哦）」
- **emoji 与星愿池 UI 元素同款**：🔥（火焰连击天数）、🎁（星路礼物盒）、⭐（星星分值）、✅（评分 tab）、📊/📈（统计）、📏/👀（身高/视力）
- **配图来源**：demo 真机截图 → zh-intro-images（9:16 市场长图）→ xhs-promo-images（3:4）；文案引用的数字/元素取自真机截图原文（如「🔥31 天」「1/1 今天的任务全部完成」「连续满 35 天遇见「辰」」「8 岁男孩身高参考 122~147.9cm」）

### CTA 生成规则（按文章主题动态生成，不再一字不改）

定位不变：告诉读者「在鸿蒙设备的华为应用市场能看到星愿池」。句式随主题换，按下面两步生成：

**第 1 步 · 选引擎句型**（任选其一，禁用「搜」等导流动词）

| 句型 | 模板 | 适用 |
|---|---|---|
| 找到式 | `鸿蒙设备的华为应用市场里，就能找到「星愿池」。` | 默认通用，最稳 |
| 存在式 | `华为应用市场的鸿蒙专区，一直有「星愿池」。` | 偏品牌感、收尾用 |
| 场景顺带式 | `这篇说的功能，鸿蒙设备都能用——华为应用市场见「星愿池」。` | 想把 CTA 融进功能语境时 |

**第 2 步 · 按主题加一句钩子**（放在引擎句前一行，可选）

- 星图/打卡类：「把打卡的心思，交给一张星图就好。」
- 兑换类：「星星是打卡挣来的，心愿是自己换的。」
- 成长档案类：「孩子的每一步，都值得被好好记着。」
- 统计/评分类：「坚持有没有用，让它替你说话。」

**合规红线（任一命中即重写）**

- 禁导流动词：搜、下载、安装、点击、前往；「找到 / 有 / 见」是安全动词
- 全文 App 全名出现 ≤3 次：首行【】1 次 + CTA 1 次刚好，钩子里不再点名
- 引导获取的完整信息由发布者放**评论区置顶**，正文 CTA 保持弱化
- 弱导流变体（营销限流风险高时用）：整条 CTA 从正文删除，只留金句收尾，CTA 信息全部移到评论区置顶

### 合规口径（星愿池专属）

- **成长档案健康表述**：全文只引用界面的「参考」「参考区间」，不下「达标 / 不达标」「正常 / 发育迟缓」类结论；禁治疗、矫正、恢复视力、防近视等医疗词；「能不能长到 xx」一律改写成「和参考区间比一比」。
- **兑换篇诱导词回避**：星愿兑换是打卡攒星换心愿，不是抽奖——不用「抽、中奖、免费领、福利放送、限时抢」这类概率促销词，保持「星星靠打卡获得，不用花钱买」的口径本身就是最好的合规表述。
- **变形规避不可取**：不在文案里用「搜s0」「搜🈚」这类变形写法，识别后判罚更重；直接用弱化版句式。
- **tag 合规**：tag 池内的 tag 不含其他平台名；发亲子篇避开「鸡娃」「牛娃」类容易被判攀比焦虑的 tag。
