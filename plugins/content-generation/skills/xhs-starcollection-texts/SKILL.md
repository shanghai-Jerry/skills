# 星愿池小红书推广文案

为星愿池（鸿蒙亲子目标打卡 App，stars-collection 项目）的功能页写小红书种草文案：一张配图 + 一篇文案成对发布。方法论全部继承 `app-promo-texts` skill（**先读它**），本篇只给星愿池专属的固定值与范文索引。

## 与 app-promo-texts 的差异点（本 skill 负责的部分）

| 骨架位置 | 星愿池固定值 |
|---|---|
| 首行标题 | `【星愿池·功能名】`（功能名 3-6 字，如 桌面卡片/成长档案） |
| 过渡句 | `星愿池怎么帮你<做的事>？` / 延续页功能可用 `星愿池怎么<动作>？`（如「星愿池怎么兑换？」） |
| 信任块 | 固定标题 `🔒 单机优先 · 无内购 · 隐私可控` + 说明「默认保存在你的鸿蒙设备本地，不强制上传云端；云端备份可选，由你手动决定」 |
| CTA（一字不改） | `鸿蒙设备可搜「星愿池」。` |
| tag 池 | `#星愿池` `#目标管理` `#鸿蒙APP` 必带 + 功能 tag + 1-2 场景 tag（如 #习惯养成 #坚持打卡 #儿童视力 #鸿蒙服务卡片） |
| 落盘位置 | `starcollection/resources/design/recommend_texts/xhs_<英文功能名>.md`，文件名与配图 `resources/design/xhs/intro_<英文功能名>.jpg` 的英文部分一致 |

## 星愿池文案特有约定

- **受众分层**：先定篇偏「成人自律」还是「亲子养娃」——星图/桌面卡片/统计/兑换偏成人语气；成长档案是家长视角（「孩子的身体数据极其私密」，隐私说得最重）
- **星星经济自洽**：树愿池的星星靠打卡获得、不能花钱买——涉及兑换/奖励的文案必须保持这个口径（「星星靠打卡获得，不用花钱买」）
- **涉儿童健康必加免责**：成长档案篇收尾前加「（温馨提示：参考标准仅供日常记录参考，不构成医学建议哦）」
- **emoji 与星愿池 UI 元素同款**：🔥（火焰连击天数）、🎁（星路礼物盒）、⭐（星星分值）、✅（评分 tab）、📊/📈（统计）、📏/👀（身高/视力）
- **配图来源**：demo 真机截图 → zh-intro-images（9:16 市场长图）→ xhs-promo-images（3:4）；文案引用的数字/元素取自真机截图原文（如「🔥31 天」「1/1 今天的任务全部完成」「连续满 35 天遇见「辰」」「8 岁男孩身高参考 122~147.9cm」）

## 流程

1. 先读 `app-promo-texts` skill 的骨架与写作特点
2. 读本表的范文中最相近一篇，再读新功能的真机截图/配图
3. 按 8 段骨架逐段填充（固定值上表直接套；自由部分按 app-promo-texts 写）
4. 过 app-promo-texts 的自检清单 + 核对星愿池口径（星星经济、隐私、CTA 原句）
5. 落盘 `recommend_texts/xhs_<英文功能名>.md`
